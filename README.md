# Mark Danila — Interactive Portfolio

Experimental React + Tailwind CSS portfolio featuring live deployments of CareerGuide and CampusSpill.

## Featured projects

- [CareerGuide](https://careerguide1.onrender.com/) — career guidance and skills assessment platform
- [CampusSpill](https://campusspill.onrender.com/) — anonymous realtime student network and PWA
- [GitHub Profile](https://github.com/Icode4youu)

## Tech stack

- React
- Vite
- Tailwind CSS
- Oxlint

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
